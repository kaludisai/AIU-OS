# AIU MASTER Map

Open `index.html` in your browser after downloading AIU-OS. No server, account or package installation is needed.

- Drag the map to orbit in 3D. Scroll to zoom.
- Select a pillar on the map or use the six buttons below it.
- Search for a starter file or skill, then follow its source link.
- Choose **Play tour** for a 20-second walkthrough of Memory, Skills and Refinement.

This is an interactive map of the public starter, using its fictional inputs and actual file paths. It does not scan your computer, import private notes or call an AI model. Personalizing the workspace does not automatically refresh the map. The curated file index lives in `app.js` and can be edited deliberately.

Keyboard users can select pillars with the buttons, search, and follow file links. Reset view restores the initial camera. For narrow windows the detail panel moves below the map.
