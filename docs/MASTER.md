# The MASTER Framework

An agentic OS is a workspace where your AI can find useful context, follow repeatable methods and save work for later. It is an arrangement of files, instructions and tools, not a replacement for your computer's operating system.

| Part | Agent's desk | Practical meaning |
| --- | --- | --- |
| Memory | Filing cabinet | Goals, facts, sources, preferences and decisions, with a map |
| Apps | Computer apps | Tools it can actually use, with verified access |
| Skills | Notebook | Saved instructions for repeatable jobs |
| Tasks | To-do list | A clear job, inputs, output location and next action |
| Evaluation | Progress report | Check the work against sources, requirements and your standards |
| Refinement | Coaching | Apply a focused accepted change and test it again |

The first three equip the agent; the last three put it to work and improve the process. External apps and scheduled tasks are optional until needed. Native agent memory can help; explicit project files make the relevant context visible and editable.

Example: Evaluation discovers the dinner plan forgot a vegetarian main. Refinement updates the planning method to check every guest's preferences, then tests a new plan. This changes saved instructions, not the model's weights.

The acronym is a map, not a mandatory installation order. Start with one useful task and add the smallest missing piece.
