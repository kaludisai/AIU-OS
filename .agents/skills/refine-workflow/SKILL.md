# refine-workflow

Read the actual output, review and user feedback. Identify one reusable principle behind the miss. If no correction is warranted, say so; do not invent work. Propose the smallest change to the relevant source, route or skill and explain why. Obtain the user's acceptance before treating it as durable guidance; an explicit request to apply a clearly specified change already supplies that acceptance. Preserve user edits and unrelated behavior. When editing a skill entry, update its matching .claude and .agents copy identically. Record the approved change using templates/feedback.md in the selected project or personal/feedback/. Rerun the affected task if authorized and available; otherwise label the retest pending. Compare the observed result against the original failed criterion. A saved coaching note alone is not a successful improvement. Never retrain the model, grant new access or publish changes implicitly.
