# Check your MASTER workspace

Use evidence from an actual task, not folder counts.

- [ ] Memory: a new session finds the relevant brief, sources and saved draft with file references.
- [ ] Apps: tool access is described honestly and external connections have dated tests when used.
- [ ] Skills: a short request follows the chosen saved method.
- [ ] Tasks: a real output exists and the next action is saved.
- [ ] Evaluation: facts, constraints and quality are reviewed; proposals and decisions remain distinct.
- [ ] Refinement: when a real correction is needed, an approved focused change is saved and the affected task is retested.

Do not invent a correction just to tick Refinement. A blank run template is not evidence. A structural check is not a quality check. Compare actual outcomes over time; do not assume a universal 10x improvement.
