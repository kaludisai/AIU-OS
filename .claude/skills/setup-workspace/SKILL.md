# setup-workspace

Ask one question at a time: what kind of work they do, one current goal, the first repeatable task they want help with, working/output preferences, and what actions need their review. Allow skipping. Never request credentials or private account exports. Save only confirmed answers to personal/brief.md; keep unanswered details visibly unknown. Personal source files belong under personal/. Link relevant source paths instead of pasting everything into the startup manual. Show the saved brief and one next task. Preserve an existing brief and its user edits; ask before replacing confirmed content. Keep the fictional practice files intact. Do not connect accounts, schedule jobs or publish anything.
