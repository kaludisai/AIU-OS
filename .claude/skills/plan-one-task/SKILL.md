# plan-one-task

Read the operating map. If the user names the fictional example, use brief/now.md and projects/first-task/README.md even if a personal brief exists. Otherwise use the selected personal brief and project. Follow assets/README.md to relevant sources. State the goal, constraints, output path and important unknowns. Ask about unknowns that change the core task; draft only independent parts while waiting. Produce a practical plan with steps, estimated quantities/costs if relevant, source paths and next action. For the dinner fixture, include a proposed menu, complete vegetarian option, estimated shopping list and preparation order. Check every supplied constraint. Save in the selected project, preserving edited or accepted work. Report the output path and pending review. Do not invent current prices, approvals, completed actions or source access. No buying, booking, sending or scheduling is authorized by this method.
