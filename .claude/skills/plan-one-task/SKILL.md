# plan-one-task

1. Read the operating map.

2. Use any brief or project path explicitly supplied by the user.

3. When the user explicitly selects the birthday-dinner fixture without supplying another path, use brief/now.md and projects/first-task/README.md even if a personal brief exists.

4. For the creator or developer exercises, use their named example brief and output path.

5. Otherwise use the selected personal brief and project.

6. Follow assets/README.md to relevant sources.

7. State the goal, constraints, output path and important unknowns.

8. Ask about unknowns that change the core task; draft only independent parts while waiting.

9. Produce a practical plan with steps, estimated quantities/costs if relevant, source paths and next action.

10. For the dinner fixture, include a proposed menu, complete vegetarian option, estimated shopping list and preparation order.

11. Check every supplied constraint.

12. Save in the selected project, preserving edited or accepted work.

13. Report the output path and pending review.

14. Do not invent current prices, approvals, completed actions or source access.

15. No buying, booking, sending or scheduling is authorized by this method.
